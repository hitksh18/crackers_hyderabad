# Website Images Folder

This folder contains all important logos and images used on the Crackers Hyderabad website.

## Important Files:

### Logos:
- **standard-logo.png** - Main Standard Fireworks logo (used on homepage hero section)
- **crackerhyderabadlogo.png** - Crackers Hyderabad logo (used in footer) - *TO BE ADDED*

### Usage:
- All images in this folder are referenced in the website code
- To update logos, replace the files with the same filename
- Recommended formats: PNG with transparent background for logos

### Adding New Logo:
1. Save your logo as `crackerhyderabadlogo.png`
2. Upload to this folder: `client/public/images/website/`
3. The footer will automatically display it
